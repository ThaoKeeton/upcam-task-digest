# UPCAM 站会日报 · Workbench 原生插件

插件版本 0.1.0，业务核心为独立版 0.4.3。此插件向统一窗口提供真正的 WinUI 页面，不会嵌入或启动另一个日报应用窗口。独立版 0.4.3 继续保留。

## 兼容范围

目前针对 `project-workbench` 的 `feat/native-plugin-workbench` 分支、API 1 开发，锁定源码提交 `6565180b17130f6d494978291df4138de3fdb0b4`。宿主使用 .NET 10 / Windows App SDK 1.8.260921001；独立版原有的 .NET 8 / 其他 WinUI 运行库不应复制到宿主插件目录。

`reference/` 是同一项目所有者授权使用的原始 SDK、Core 和测试宿主源码快照；`source-manifest.json` 记录每个文件的原始 Git blob。它用于离线构建和验证，不是要再次安装到宿主的运行库，也不表示新增了未经核实的第三方许可证。

## 安装与首次使用

1. 完整解压正式插件 ZIP。选择其中的 `com.upcam.task-digest` 文件夹，而不是 `worker` 文件夹。
2. 在兼容的工作台中安装该目录。安装只复制文件；插件默认未启用。查看来源并通过工作台原有的信任流程启用插件。
3. 打开“UPCAM 站会日报”或对应设置页面，连接本机无窗口业务进程。新安装默认使用工作台为插件分配的数据目录，不会自动查找、读取旧版密钥。
4. 首次配置在插件设置页完成，保存后的项目范围仍需实际只读核验。配置迁移不会代替真实项目核验、扩大自动发送权限，或绕过缺失映射与采集完整性检查。

正式包名称含 `production`；名称含 `acceptance` 的包只用于 CI 虚构数据验收，页面会明确显示测试标识，不应用于真实项目。

## 接续独立版数据与回退

先完全退出独立版，再在插件的数据目录设置中指定原有独立版数据文件夹。接续绑定的是原目录，配置、Windows 当前用户 DPAPI 凭据、模型缓存、运行记录、采集进度和发送账本继续共用；不会生成可独立调度的副本。路径必须是本机绝对目录，不能是网络目录、链接或磁盘根目录。

同一登录会话使用与独立版一致的互斥标识，避免两者同时运行。用户若要回退，先停用插件或完全退出工作台，等待业务进程结束，然后启动保留的独立版 0.4.3。接续原目录后，后续记录仍在原处。不要在另一账户或另一电脑上复制 DPAPI 文件来尝试解密，也不要让其他旧进程绕过互斥标识运行。

独立版的开机启动、托盘、语言、主题和更新偏好保留在原配置中；插件不会修改注册表或替工作台设置全局偏好。使用插件时，窗口、托盘、开机启动和工作台本体更新由宿主管理。切换运行方式后，请使用宿主或独立版现有界面选择唯一的日常启动入口。

## 自动运行与当前平台接口限制

只有已有配置明确启用自动发送且通过核心校验时，插件才沿用该授权。插件安装、启用或选取数据目录本身不会新开启自动发送；人工操作和定时任务仍经过原有程序校验与发送账本。

已核实的平台 SDK 暂无“插件已成功启用”的公开回调。在该版本宿主下，需要在每次宿主启动后打开一次日报页面或执行插件命令，才会连接后台并启动已授权的调度；切换到其他页面后仍继续运行，停用插件则停止。不能声称仅恢复插件的启用状态就已实现无人值守开机调度。完整自动恢复需要平台提供启用提交后的生命周期回调；本仓库不修改平台代码，也不利用延时猜测启用是否完成。

工作台退出、电脑休眠、断网或用户尚未登录期间无法保证按点执行；沿用核心已有的恢复窗口和防重规则，不会无限追发历史日报。

## 取消、超时与未知发送结果

普通操作有 30 秒期限，采集类操作最多 125 分钟。取消、超时或协议损坏会断开并终止插件自己拥有的业务进程，不自动重放请求。特别是发送中断时，消息可能已经发出：重新连接后应查看运行记录，原有未知发送结果防护继续有效。只有显式操作才会重新连接；插件不会循环重启并盲目重试发送。

## Windows 构建与验证

在 Windows 上安装 Python 3.12、`requirements-build.txt` 和匹配的 .NET 10 SDK：

```powershell
python -m unittest discover -s tests -v
pwsh -File integrations/project-workbench/build-plugin.ps1 -BuildAcceptance
```

生成的正式包位于 `dist/workbench-plugin/`。`plugin-package.json` 及 ZIP 旁的 SHA-256 用于发现构建或传输错误，**不是独立可信的发布者签名**。宿主仍应执行自身的包审查和信任检查；本插件没有自动下载或替换宿主/插件的更新器。

Windows CI 另外运行进程故障测试和基于真实锁定 SDK/Core 的原生验收宿主，结果以报告中列明的检查为准。此验收宿主不能替代用户最终安装电脑、真实项目权限、钉钉客户端展示或未测试的新宿主版本验证。所有开发验收只使用虚构数据，不填真实密钥，不发送钉钉。
